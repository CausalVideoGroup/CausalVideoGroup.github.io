# Video Editing Frontiers — Idea Map

- Editing mechanisms: inference transport, instruction training, semantic planning and rendering.
- Controllable changes: local attributes, composition, motion, object interaction, counterfactual effects.
- Persistent editing: long video, multiple shots, history, instruction updates and undo.
- World models: state recovery, interventions, consequences and prediction feedback.
- Agents: executable plans, tools, verification, repair and fixed-budget evaluation.
- Evidence: source-object identity, event completion, non-target preservation and calibrated judges.

The dog–bone example connects object identity and contact to state recovery and judge validity. Multi-turn editing connects versioned state to agent rollback and session-level evaluation.
