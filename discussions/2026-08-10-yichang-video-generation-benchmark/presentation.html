09 · Human evaluation

人工评测也不是一个统一的数字

PAIR
2AFC强制二选一；输出 win rate，不能表达绝对质量。
ORDER
Rank一次排序多个模型；认知负荷和候选集合会影响结果。
SCALE
Likert绝对打分；不同评分者的尺度需要校准。
ARENA
Elo / BT由 pairwise 结果拟合相对强度；依赖配对图与更新规则。
TIES
GSBGood／Same／Bad；tie 的编码会改变最终估计。
REALITY
Real vs Gen测可辨别性，不等同于文本对齐或世界一致性。

14 · Three families of 3D evaluation

3D consistency 的评测方法可分为三类

图像对应约束

在帧间建立像素或特征对应，检验这些对应是否满足同一相机几何。

Epipolar constraint · Sampson error · reprojection error
代表：WorldScore

深度／点云几何

估计深度、point map 与相机，将多个视图投影到共同三维坐标系后比较。

Point-cloud alignment · cross-view warping · MEt3R
代表：MEt3R

逐视频 3DGS 重建

用生成视频拟合 3DGS，再在未参与拟合的视角上验证重建一致性。

3DGS · held-out-view PSNR／SSIM／LPIPS
代表：Cosmos-Predict1
共同边界　DINO／CLIP 相似度与 VLM 判断可以作为补充证据，但不构成三维几何测量。

21 · A lean but hard protocol

聚焦且可审计的协议，优于宽泛而松散的指标集合

STATE

实体身份、阶段进度、位置、形状与几何。

SPECIALIST

可审计自动指标

分割、跟踪、pose、重建与过程特定测量。

SEMANTICS

VLM 处理剩余语义

CALIBRATION

人工只审分歧样本

按 failure type 报告 human–metric disagreement。

讲稿提示

术语表

Metric lineage
指标的算法与协议来源，例如 VBench、paper custom 或环境任务分数。
Prompt lineage
输入内容与选择规则的来源，例如 MovieGenBench、VBench official 或自定义轨迹。
Proxy metric
用可测信号近似目标能力，例如用 DINO 特征相似近似身份一致性。
3D consistency
不同视角能否由同一空间几何解释。
Revisit consistency
离开并返回旧位置时，场景或状态是否被正确恢复。
Out-of-sight consistency
对象不可见时，隐藏状态是否仍按规律演化并在再出现时正确呈现。
Sampson error
由特征对应与基础矩阵得到的近似极线几何误差。
3DGS
3D Gaussian Splatting。用生成视频拟合三维表示，再在保留视角验证可重建性。
MEt3R
基于点云跨视图投影的几何一致性证据。
